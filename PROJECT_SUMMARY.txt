================================================================================

  - 30+ FPS (Frames Per Second)

MATHEMATICAL FOUNDATIONS
════════════════════════

1. 3D Joint Angle Computation
   ──────────────────────────
   angle = arccos(v1 · v2 / (||v1|| ||v2||))
   
   Where:
   - v1 = point1 - joint
   - v2 = point2 - joint
   - Output: 0-180 degrees

2. Joint Velocity
   ──────────────
   velocity = ||position_t - position_t-1||
   
   Computed over 30-frame history

3. Object Keypoint Similarity (OKS)
   ────────────────────────────────
   OKS = exp(-d_i² / (2 * σ_i² * scale²))
   
   Standard COCO metric with joint-specific sigma values

4. IoU (Intersection over Union)
   ────────────────────────────
   IoU = correctly_detected_joints / total_joints
   
   Joint considered correct if distance < threshold

5. Average Precision
   ─────────────────
   AP = (1/11) * Σ max(precision @ recall ≥ t)
   
   11-point interpolation across recall levels

→ Try min_detection_confidence=0.3

Low FPS:
→ Use model_complexity=0
→ Reduce resolution
→ Enable GPU

→ python -m pip install --upgrade -r requirements.txt

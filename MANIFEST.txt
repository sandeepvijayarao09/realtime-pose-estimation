   Advanced spatial analysis and activity classification
   Classes:
   - JointAngle: 3D angle with confidence
   - JointVelocity: Velocity vector data
   - SpatialReasoning: Main spatial analysis engine
   - RepCounter: Repetition counter with state machine
   Key methods: compute_joint_angle, compute_all_joint_angles,
               compute_joint_velocity, compute_joint_acceleration,
               classify_activity, count_reps, get_pose_vector
   Features: Accurate 3D vector math, 30-frame history, 11 activity classes

4. src/activity_classifier.py (397 lines)
   LSTM-based deep learning activity classifier
   Classes:
   - ActivityClassifier: LSTM sequence classifier
   - FeatureExtractor: Feature extraction utilities
   Key methods: add_frame_to_sequence, predict_activity, train, evaluate,
               save_model, load_model, clear_sequence
   Features: 2-layer LSTM, feature normalization, fallback heuristic mode,
             11 activity classes, optional TensorFlow support

5. src/metrics.py (393 lines)
   Comprehensive evaluation metrics and benchmarking
   Classes:
   - PoseMetrics: Pose evaluation metrics
   - SkeletonIoU: Skeleton-specific IoU

   - SkeletonMetrics: Skeleton quality metrics
   Key methods: compute_iou, compute_oks, compute_average_precision,
               compute_map, compute_precision_recall, compute_f1_score

             timing statistics, connection-based IoU

================================================================================
KEY FEATURES BY MODULE
================================================================================

POSE ESTIMATOR
- 33-landmark full-body detection (MediaPipe Holistic)
- Normalized 3D coordinates (x, y, z, visibility)
- Real-time FPS tracking with configurable window
- Skeleton visualization with customizable drawing
- Static or tracking mode support

SPATIAL REASONING
- 3D joint angle computation using vector dot products
- 8 major joint angles (shoulders, elbows, hips, knees)
- Frame-to-frame velocity computation
- Velocity-based acceleration
- Heuristic activity classification (11 activities)
- Repetition counting with state machine
- ML-compatible pose vector extraction

ACTIVITY CLASSIFIER
- LSTM-based sequence modeling (2 LSTM + 2 Dense layers)
- 30-frame sliding window sequence input
- 68-dimensional pose feature vectors
- Feature normalization for training stability
- 11 predefined activity classes
- Fallback heuristic mode (no TensorFlow required)
- Model persistence (save/load)

METRICS & BENCHMARKING
- IoU (Intersection over Union) for skeleton evaluation
- OKS (Object Keypoint Similarity) - COCO standard
- mAP (Mean Average Precision) with 11-point interpolation
- Precision-Recall curves for detection analysis
- F1 scores for balanced evaluation
- Real-time FPS tracking with statistics
- Connection-based skeleton IoU
